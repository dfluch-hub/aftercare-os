# AFTERCARE RECOVERY COMPANION PACK — ETSY PRODUCT

This is the Etsy-specific downloadable companion product.

## Files to design before listing

1. `01_First_Day_Home.pdf`
   - top 3 priorities
   - trusted care instructions
   - next visit
   - who is helping

2. `02_Medication_Overview.pdf`
   - name
   - timing
   - instructions copied from trusted source
   - notes

3. `03_Questions_For_Care_Team.pdf`
   - question
   - answer / note
   - follow-up needed

4. `04_Caregiver_Handoff.pdf`
   - what is scheduled today
   - practical helper notes
   - trusted contact note

5. `05_Appointment_Overview.pdf`
   - date/time
   - clinician
   - location
   - questions
   - notes

6. `06_Recovery_Notes.pdf`
   - date
   - pain value user wishes to record
   - energy
   - daily function
   - notes

7. `07_Quick_Start.pdf`
   - what each page is for
   - non-medical disclaimer

## Etsy positioning

Headline:
**A calm recovery organizer for the days when your brain is already full.**

Secondary hook:
**Printable companion sheets for post-surgery and hospital-discharge organization.**

Do not present the companion pack as medical advice or a clinical recovery plan.
